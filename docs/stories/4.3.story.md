## 1. User Story

**Como** Anfitrión e Inquilino de Media Estadía (30 a 180 noches)
**Quiero** que el sistema redacte automáticamente el Contrato de Locación Temporaria válido bajo el Código Civil y Comercial Argentino en formato PDF y lo selle criptográficamente con `SHA-256` al firmarlo electrónicamente
**Para** ambas partes contemos con respaldo jurídico inmediato y garantía en custodia (Escrow) contra la inflación.

---

## 2. Acceptance Criteria (Given / When / Then)

### AC-1: Contrato PDF sellado (`FR-15`, `FR-16`)
* **Given** una reserva de Media Estadía (`nights_count >= 30`)
* **When** se ejecuta `generateAndSignContractAction(bookingId)`
* **Then** el servidor construye el binario PDF real usando `pdf-lib` con las cláusulas del Art. 1199 CCyC, datos de las partes, finalidad de la estadía, monto mensual y garantía en Escrow
* **And** calcula `crypto.createHash('sha256').update(pdfBuffer).digest('hex')`, sube el PDF a Supabase Storage y persiste el hash de 64 caracteres en `public.contracts`.

### AC-2: Reservas cortas
* **Given** una reserva con menos de 30 noches
* **When** se invoca la acción
* **Then** se rechaza con error de validación (`VALIDATION_ERROR`, HTTP 422).
